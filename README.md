# Code for "Finding optimal measurement sequences for broken or constrained measuring devices" <br> [doi 10.48550/arXiv.2611.02470](https://arxiv.org/abs/2611.02470)

This code implements the methods presented in the journal article "Finding optimal measurement sequences for broken or constrained measuring devices". To run this code requires `Racket`, although it should also run under most Scheme implementations with slight modification. Download a snapshot of the repository's files as a zip file to your local computer, and then unpack the zip file.
